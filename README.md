# PhoneTrace 1.0
Статичний сайт українською. Завантажте файли в корінь репозиторію GitHub, відкрийте Settings → Pages → Deploy from a branch → main → / (root) → Save. Відкрийте адресу, яку покаже GitHub Pages.
Для роботи потрібен інтернет: бібліотека libphonenumber-js завантажується з jsDelivr. Номер обробляється в браузері, не надсилається пошуковим API та не зберігається застосунком. CDN отримує звичайні мережеві метадані запиту бібліотеки.
Перевірка формату не підтверджує активність номера. Пошук власників, операторів, відгуків та автоматична перевірка спаму не реалізовані. PDF через функцію друку браузера.
